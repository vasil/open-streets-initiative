## Today's Goals

### 1. Sensor Import (`sensors.py`)
Implement the `sensors` command to ingest raw sensor recordings (accelerometer/gyroscope) into the local data store.

- Define a sensor recording file format (CSV or JSON)
- Parse timestamps, x/y/z accelerometer values, and gyro values
- Store imported recordings in `data/sensors/` as one file per session
- Validate that timestamps are present and in UTC

### 2. Activity–Sensor Matching (`match.py`)
Implement the `match` command to link sensor sessions to Strava activities by timestamp overlap.

- For each sensor recording, find the Strava activity whose start/end time bracket it
- Write a match index to `data/matches/` (sensor file → activity file mapping)
- Handle edge cases: no match found, partial overlap, multiple activities

### 3. Analysis Stub Upgrade (`analyze.py`)
Begin implementing RFC (Relative Fatigue Cost) scoring from matched data.

- Load matched sensor + GPS data
- Compute per-second vibration magnitude from accelerometer (√(x²+y²+z²))
- Aggregate by GPS segment (street-level resolution)
- Output a scored segment list as JSON

---

## Guiding Principles

- **Local-first** — no raw data leaves the machine
- **Timestamps are the link** — sensor session ↔ Strava activity matched by time overlap
- **Evidence over opinion** — every street score must be traceable to raw sensor readings
